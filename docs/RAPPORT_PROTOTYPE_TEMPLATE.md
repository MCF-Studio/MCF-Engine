- **Révision / commits :**

## 1. Question à trancher

Formuler l'hypothèse testée et la décision que le résultat doit éclairer.

## 2. Sources et dépendances

| Élément | Version / commit | Licence | Compatibilité vérifiée | Source |
|---|---|---|---|---|

## 3. Environnement reproductible

- Matériel : processeur, mémoire, GPU, disque.
- OS, pilote GPU et version de Rust.
- Version de Bevy et profil de build.
- Paramètres exacts : résolution, vsync, scène, graine, durée de chauffe,
  durée de mesure et nombre de répétitions.

## 4. Procédure

Commandes, données d'entrée, parcours et critères d'arrêt. Toute manipulation
manuelle doit être décrite.

## 5. Résultats bruts

| Run | Frame moyenne / p99 / 1 % low | CPU | GPU | RAM / VRAM | Entités / secteurs | Réseau ou chargement |
|---|---|---|---|---|---|---|
| | | | | | | |

Joindre les CSV, traces ou captures référencés par chemin, sans substituer une
conclusion aux mesures.

## 6. Limites et anomalies

Ce qui invalide, limite ou rend difficilement comparable le résultat.

## 7. Recommandation

Choisir explicitement : intégrer, itérer, comparer autrement, surveiller ou
rejeter. Préciser les preuves manquantes et l'ADR à créer si une décision
structurante est proposée.
