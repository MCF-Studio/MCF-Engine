# Conception du JEU (pas du moteur)

Ce dossier contient les notes de **game design** du jeu RP de MCF Studio : ce que vivent les joueurs, les règles du
jeu, l'économie, les activités. Elles servent **quand on fera le jeu** (phase 10 de `ROADMAP.md`, transition du jeu),
pas pendant la conception du moteur.

Règle pour ne pas se mélanger les pinceaux :

- **Ici** : le fonctionnement côté joueur (« on monte dans la fusée, on contrôle un drone lunaire »).
- **Dans `ROADMAP.md` et `mcf/docs/`** : seulement les **capacités du moteur** qu'une note de jeu exige (« plusieurs
  zones par serveur, gravité par zone »), formulées sans détail de gameplay, avec un renvoi vers la note.
- Une note de jeu peut changer sans toucher au moteur. Si un changement de jeu exige une nouvelle capacité moteur,
  on l'ajoute explicitement à la feuille de route : jamais de « au passage » dans le code du moteur.
